# WTZ 的个人网站

一个部署在 GitHub Pages 的**黑白终端风**个人站点群：以 `index.html` 为总入口，串联论坛、学院官网、小游戏终端、泰拉大典、机密终端等独立子站，并配套本地/云端 Flask 服务端（留言、用户、论坛、私聊、AI 中转、风控）。

- 线上地址：https://wtz-YEE.github.io/
- 仓库：https://github.com/wtz-YEE/wtz-YEE.github.io
- 主入口：`index.html`

## 启动动画

所有主要界面通过 `intro.css` + `intro.js` 注入 1.05–1.25s 的专属启动层，页面用 `<body data-intro="…">` 选择动画：首页黑白六边形开屏、项目档案切页、游戏 CRT 开机、社区信号波纹、杂项齿轮、开发中警示带、视频胶片倒计时、管理后台扫描网格。层可点击或按 Esc / Enter 跳过；`prefers-reduced-motion` 下自动禁用。

## 全站导航

`nav.css` + `nav.js` 统一替换旧的 `header.top` / `header.cm-top` / `header#status` / 带 `.logo` 页面头部，生成同一套黑色终端导航：品牌标记、首页 / 项目 / 游戏 / 社区 / 杂项 / 视频库 / 开发中七项、当前页高亮、页面时钟、局部徽章与登录按钮保留。窄屏自动收进右侧抽屉；旧头部中的时钟、成就/权限徽章、私聊/通知按钮会迁移到新导航，不丢功能。

## 核心功能

**总入口与分区（v3 架构）**
- `index.html` 只做门户：封面、四分区大卡、快捷入口、页脚，不再承载工具与社区功能
- `项目.html` / `游戏.html` / `杂项.html` 汇总原有子站链接，页头带分区编号与入口计数
- `社区.html` 承接原 index 的社区部分：登录注册、留言板（点赞/共鸣/引用/举报/标签/图片/头像）、私聊、公告、通知中心、个人主页、排行榜、积分商店、访客墙
- 管理员后台独立为 `管理后台.html`：社区页原管理面板位置只留一个入口，管理页复用 `gb_api_url` / `gb_session`，登录时二次校验 `is_admin`；服务端仍对每个管理员接口做权限校验
- 管理页视觉为黑底 + 米白 + 亮黄（`rgb(255,241,0)`）的控制室风格；`admin.css` / `admin.js` 独立维护，不加载社区脚本
- 备忘录从 index 移到 `杂项.html`，由独立 `misc.js` 实现（Markdown 渲染、任务勾选、进度/目标、导出、登录时同步 `/pref_set`）
- 样式分为 `portal.css`（门户与三张分区页）与 `community.css`（社区页，复用 `index.css` 的留言板/弹窗/商店基础样式）

**视频库**
- 已完成并从「开发中」移出，首页新增独立推荐卡与今日主推
- 首页推荐：按播放、点赞、评论、发布时间和分区新鲜度综合打分，自动选今日主推与前两条推荐
- 列表页：搜索（标题/作者/标签）、分区筛选、推荐/最新/播放/点赞四种排序、推荐头图、封面临时占位
- 完整观看：播放进度记忆、自动连播、下一支、复制链接、点赞、评论、相关推荐、删除自己的视频
- 投稿页：视频压缩、封面上传、分区/标签、我的投稿与云端视频库列表；封面会随视频一起存入云端
- 视觉：白底 + 青字 `#00A0B0 ~ #0098A8`

**守夜人论坛**
- 发帖（图片、标签）、评论、Markdown（粗体/代码块）、赞踩、热门置顶、@提醒
- 风控：管理员上传关键词，主机每 10s 自动扫描，命中即删除用户（浏览器端标记危险账号、24h 禁注册）

**卡塞尔学院官网**
- 血统测评：绘画抽象度分级 F / E / D / C / B / A / S
- 诺玛 AI：主机中转在线大模型（OpenAI 兼容接口，默认 DeepSeek），客户端填 API Key；降级链：真 AI → 主机知识库 → 本地 KB
- 学院知识库：人物档案、言灵周期表、核心设定、主线时间轴、隐秘档案、原著搜索（已按《龙族》原著多轮精确核验）
- 权限系统：密令 + 血统评级提升权限；首次进入需签订亚伯拉罕血统契

**终端接口**
- 24 个小游戏按权限分组逐步开放（组 1 / 组 2 / 组 3）
- 成就系统：干各种事获得（20 基础 + 30 隐藏，UI 不可见）
- 与作者对战：成就满 30 或 2048 彩蛋解锁，5 形态 boss 战（玩家攻击手段由作者技能演化）

**服务端（_gb / _cloud）**
- Flask 单文件服务，端口 8701
- 数据文件（JSON）：`users.json`（含会话、封禁）、`posts.json`、`guestbook.json`、`pm.json` 等
- 接口：留言（/guests、/guests_new）、论坛（/post_get、/post_add）、登录注册、私聊、通知、成就、排行、版本 changelog、AI 中转（/noma_ai、/noma_ask）、风控关键词扫描
- 写接口 1.5s/IP 限流
- 多云端集成：`一键启动云端.bat` + cpolar 隧道，主机地址写入 `cloud.txt` / `云端地址.txt`，前端 `ga()` 自动读取（不写死内置地址）

## 部署

- **GitHub Pages**：`tools\自动上传.bat` 一键 commit + push → https://wtz-YEE.github.io/
- **云端服务**：cpolar 内网穿透（需先 `cpolar authtoken <令牌>`），隧道地址写入 `cloud.txt`
- 服务端两份同步：`_gb\guestbook_server.py`（本地权威，gitignore）+ `_cloud\guestbook_server.py`（提交线上）
- 改动服务端后：同步两份 → `py_compile` 校验 → 重启 8701 → 用 `_gb\_noma_test.py` 复测

## 技术栈

- 纯静态前端：原生 HTML/CSS/JS（无构建），黑白终端美学，Canvas（游戏/测评）
- 服务端：Python Flask（标准库 urllib 中转 AI，无第三方依赖）
- 数据：本地 JSON 文件存储
- 部署：GitHub Pages + cpolar 内网穿透
