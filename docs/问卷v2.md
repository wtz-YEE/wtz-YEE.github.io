# 网站问卷 · 第二版（成长闭环上线后）



---

## 一、为什么重写

v1 问的是「你想加什么」，当时网站缺的是**功能**。那一轮之后已经上线了两批：

| 批次 | 内容 | 状态 |
|---|---|---|
| 第一批 · 探索闭环 | 每日签到 / 每日谜题 / 密文解码器 / 访客墙 / 站点地图 / 罗德岛通讯 | v1 之前已上线 |
| 第二批 · 成长闭环 | **积分商店 + 称号 / 头像框、成就墙（50 项）、全站排行榜、玩小游戏产积分** | 本版新增 |
| 探索加强 | **世界碎片收集（22 页各一枚）、诺玛 AI 新手引导** | 本版新增 |

所以 v2 的问题要换：

- v1 是「**你们还想要什么**」
- v2 是「**新东西真的好用吗，下一步该修还是该加**」

**v1 那一份回答（每天来 / 要探索感 / 愿意试毒）已经把"要不要做成长闭环"这个问题回答了，本版不再重复问。**

## 三、和 v1 的对照

| | v1 | v2 |
|---|---|---|
| 核心问题 | 你想要什么功能 | 已做的功能有没有用 |
| 选项性质 | 全是"加" | **含"修"** |
| 是否问设备 | 否 | **问** |
| 是否问负反馈 | 否 | **是（Q3）** |
| 是否问传播 | 否（只有"愿意帮什么忙"） | **是（Q6）** |
| 开放题 | 无 | **有** |
| 题量 | 5 题（4 单选 + 1 多选） | 8 题（6 单选 + 1 多选 + 1 开放） |

**题量说明**：v2 多 3 题，但 Q5/Q6/Q7 都是"看一眼就能选"的题，实际填写负担不大。如果担心流失，可以砍掉 Q7（设备）——它的信息也能从服务端 `pref` 和访问日志间接得出。

## 四、发问卷之前，建议先做两件事

这两件都不是代码问题，但会直接影响问卷回收质量：

1. **把新功能写进更新日志**。
   现在 `changelog.html` 最新一条还是「主题大升级」（id 8），
   积分商店 / 排行榜 / 成就墙 / 碎片 / 诺玛引导**一条都没记**。
   用户回答 Q2 时会去找"新东西在哪"，更新日志是第一落点。

2. **确认积分真的攒得动**。
   实测本机 8 个账号里只有 1 个有非零积分（15 分），最便宜的商品 40 分。
   如果大部分人 Q5 选「0」，说明要先调积分产出，而不是急着加新功能。
