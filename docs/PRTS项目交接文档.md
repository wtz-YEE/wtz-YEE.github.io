## 4. 权限体系（终端接口核心）

### 4.1 等级结构

- **LV0**：初始，只能看到权限提升入口与基本信息
- **LV1–LV8**：逐级开放，组 N 需 LV N（游戏组 1 需 LV1 … 组 8 需 LV8）
- **LV9999（乱码 ▓▓▓▓）**：秘技权限，全内容解锁，界面变红，所有小游戏开启作弊模式
- 直开高权限页（如 LV1 直接输游戏-04.html）会被全屏「ACCESS DENIED · 需要权限 N」拦截

### 4.2 权限提升（access / 卡片问答）

提升方式：终端输入 `access` 或点击主窗口权限卡片 → 弹出问答，答对升 1 级。问答表（8 项）：

| 提升至 | 问题 | 答案 |
|---|---|---|
| LV1 | wtz 的年龄？ | 13 |
| LV2 | wtz 的微信头像中的物品是？ | 扳手 |
| LV3 | wtz 的 CN 是？ | 81A |
| LV4 | wtz 的 GitHub 用户名是？ | wtz-yee |
| LV5 | wtz 主要用什么引擎做游戏？ | godot |
| LV6 | wtz 的站点主目录名是？ | prts |
| LV7 | wtz 仿写/参考的沙盒魔法游戏是？ | noita |
| LV8 | wtz 自研的肉鸽游戏名是？ | 泰拉肉鸽 |

另有遗留捷径：sessionStorage `wzKey==='3'` 时折算为 LV3。

### 4.3 秘技 9999（2048 彩蛋）

1. 在 游戏-01.html 的 2048 界面，**键盘**依次输入 `↑ ↓ ↑ ↓ ← → ← →`
2. 点击「新游戏」→ sessionStorage 写入 `wzLv=9999` + `wzCb=1` 并跳转主终端
3. 主终端检测到后触发崩坏 glitch 特效（约 2.6s）→ 自动进入「与作者对战」（#/w）

> 注意：序列必须通过 `document.dispatchEvent(new KeyboardEvent('keydown', …))` 派发到 document 才被 2048 监听接收；窗口级派发无效。

秘技生效后所有小游戏进入作弊模式：2048 合成得分 x2、小恐龙撞碎障碍、贪吃蛇穿墙、方块不停、扫雷显雷、砖块宽板、管道可穿、战机 0.01s 射速。

## 6. 机密终端（密钥体系）

入口：终端接口 `secret` 命令（LV3+）。布局：类 cmd 命令窗口 + 内部数据库（所有密钥解法已索引）。

### 6.1 三层密钥（随时间变化）

| 层 | 名称 | 规则 |
|---|---|---|
| 第 1 层 | 密钥 | 问题：wtz 最喜欢的角色是？ 答案：**cyrene**（小写） |
| 第 2 层 | 时间密钥 | `日(2位) + 时(2位) + (日×7+时×3)%100` 共 6 位，随当前日期与钟点变化 |
| 第 3 层 | 解码校验 | 明文 = `日2位+时2位+(日×11+时×7)%100`；位移 `w[i]=(日×(i+1)+时)%10` 每位不同；密文 = 逐位 `(明文+w[i])%10` 后整串**倒序**显示；需解出 6 位明文 |

示例（某时刻）：明文 123456 → 每位加位移 975319 → 密文倒序 913579；解码时倒序回 975319 → 逐位减位移 → 123456。

### 6.2 密钥生成脚本

`gen_keys.py`（仓库根目录）：运行即输出当前时间的第 2 层密钥与第 3 层密文/明文；支持参数指定日、时（`python gen_keys.py 日 时`）。

### 6.3 命令

`help/?` · `keys/db/数据库`（全部密钥解法）· `key1` · `key2/timekey`（实时）· `key3/cipher`（实时密文+SHIFT）· `perm`（三级答案）· `secret/9999` · `verify`（三重验证流程，依次输入 cyrene → 时间密钥 → 解码明文）· `cloud/visitors`（云端访客列表）· `whoami` · `clear/cls` · `lock`（锁定返回）· `exit/back`

## 11. 维护约定（重要）

1. **改前备份**：任何修改前将当前版本复制到 `_backup\`（如 `终端接口-改动前.html`）；`_backup\` 不属于交付物
2. **上传规则**：未经用户明确指示**不得** push GitHub；用户说「上传」才执行
3. **代码风格**：新代码无注释、变量名尽量精简（用户偏好）
4. **项目结构**：用户改过目录结构后，保持兼容，不擅自改回
5. **单文件原则**：每个页面自包含 HTML，不拆 JS/CSS；图片走 `assets/` 相对路径
6. **密钥**：第 2/3 层密钥随时间变化，交接后按 `gen_keys.py` 或终端 `keys` 命令实时获取
7. **卡住先查 `项目易错清单.md`**：收录真实踩过的坑（云端连不上 / 登录 500 / 限流 429 / 环境坑）与 30 秒排障顺序；修完新问题请补一条进去
