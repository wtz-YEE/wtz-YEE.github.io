## 建议的 "一起改" 分批顺序

- **第一批・探索闭环**（半天工作量，全是 S）：每日签到 + 每日谜题 + 访客墙 + 广播通讯 + 全局导航
- **第二批・成长闭环**：积分经济 + 商店 + 称号 + 成就墙 + 排行榜
- **第三批・世界感**：阵营 + 干员收集 + 碎片收集 + AI 引导 + 宠物

**一个联动提醒**：第二批起 users.json 会加新字段（积分 / 阵营 / 签到），你现有的云端同步合并逻辑（按 id 去重、分数取高）要把新字段一起加进合并，否则云端会丢数据。
