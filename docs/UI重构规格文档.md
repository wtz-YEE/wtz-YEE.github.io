# 首页 UI 重构规格文档（index.html · v1）

> 文档日期：2026-10-04 · 交付对象：主程 · 改动范围：`D:\WTZ\prts\index.html`（骨架 + CSS 变量）
> 原则：**只改结构与样式，功能零改动**。留言板 / 访客墙 / 站点地图等现有 JS 全部原样复用，仅调整容器结构与收折状态。
> 维护约定沿用交接文档：改前备份到 `_backup\`；新代码无注释；变量名精简；不上传 GitHub（除非用户明确指示）。

## 1. 背景：当前 UI 的 6 个问题（编号 P1–P6）

| 编号 | 问题 | 代码事实 |
|---|---|---|
| P1 | 卡片身份混乱 | 同一 3 列网格混排 4 张导航卡（`<a class="card">` 点击跳转）+ 3 张功能卡（`<div class="card">` 点击弹窗 / 内嵌交互）。视觉相同、行为不同，用户无法预判"点了去哪"。 |
| P2 | 入口重复 | hero 区写死"4 入口"文案（L960 `FILE WTZ·ROOT · 4 入口`），下方卡片区又是同 4 个入口。 |
| P3 | 留言板权重失衡 | 巨型 `.gb` 区块（登录 / 公告 / 私聊 / 留言列表 / 用户管理 / 风控）横在页面中段，首页被拉长一倍，主次不分。 |
| P4 | 缺少信息层级 | 卡片区无区块标题（`.b-head` 存在但未使用），`hero → 卡片 → 留言板 → 配色设置` 四段无节奏、无分组。 |
| P5 | 控件过密 | 登录行 5 控件、用户信息行 7 按钮（签到/导出/改密/安全问题/登出…）、留言头排序下拉 + 刷新按钮同屏堆叠。 |
| P6 | 全站风格漂移 | index 黑白风 vs 终端接口青色 `#3FE0C8` vs 莱茵生命另一套；圆角 / 间距 / 字体各页不一。 |

**本次交付目标**：修复 P1–P5（index 单页），P6 只在本页落地变量规范，全站推广列入后续批次。

## 3. 设计规范（主程按此值执行）

### 3.1 间距体系（4px 基数）

| 令牌 | 值 | 用途 |
|---|---|---|
| `--sp-1` | 4px | 徽章内边距、角标偏移 |
| `--sp-2` | 8px | 卡片内小间隔、按钮间距 |
| `--sp-3` | 12px | 卡片内边距（卡片 `padding:13px 15px` → 统一 12px） |
| `--sp-4` | 16px | 区块标题与网格间距 |
| `--sp-6` | 24px | 区块与区块间距 |
| `--sp-8` | 32px | hero 与首区块间距（现有 `.block{padding:26px…}` 改为 `padding:var(--sp-8) …`） |

- 卡片网格 `gap` 统一 `14px`（现有 `.grid.two{gap:14px}` 保留，不重复定义）。
- 页面内容宽度统一 `max-width:980px`（现有值保留）。

### 3.2 区块分组与编号标题

卡片区按 4 个分区重排，每区使用现有 `.b-head` 结构（编号 + 标题 + 右侧 `b-code` 代码注释）：

```
01 · 入口（4 张导航卡）      → 档案室 / 论坛 / 学院 / 日志
02 · 工具（3 张功能卡）      → 备忘录 / 访客墙 / 站点地图
03 · 社区（留言板，收折卡片）
04 · 设置（配色 / 主题，保持现有位置）
```

- 编号格式：`01 · 入口`（`.b-no` 内），标题 22px，右侧 `.b-code` 如 `GRID · 3COL`。
- 分区顺序不可调换；移动端（≤900px）网格降为单列（现有断点保留）。

### 3.3 卡片身份标记（解决 P1）

- 给 3 张功能卡加类 `is-tool`：`<div class="card is-tool" …>`。
- CSS 追加（无注释，变量精简）：

```css
a.card::after{content:"↗";position:absolute;right:10px;bottom:8px;font-size:11px;color:var(--ink3);z-index:2}
.card.is-tool::after{content:"⚙"}
.card.is-tool .c-go{color:var(--ink2)}
```

- 效果：导航卡右下角 `↗`，功能卡右下角 `⚙`，一眼可辨。

### 3.4 留言板收折（解决 P3，重点）

1. 结构：`.gb` 外层包一层卡片容器：

```
<div class="card gb-card" id="gbCard">
  <div class="gb-card-h" id="gbCardH">   ← 头：GUESTBOOK · N 条 + 展开/收起按钮
  <div class="gb-body" id="gbBody">      ← 现有 .gb 全部内容原样移入
```

2. 状态：默认折叠；`#gbCard.collapsed .gb-body{display:none}`。
3. JS（仅新增，不改现有逻辑）：
   - `#gbCardH` 点击切换 `.collapsed`；
   - 收起状态写 `localStorage['gb_collapsed']`，刷新恢复；
   - 展开时若 `#guestbookList` 为空则调用一次现有刷新（复用现有 `gb` 刷新函数，不重写）。
4. 头行文案：`GUESTBOOK · <span id="gb_cnt">N</span> 条`，N 取现有统计逻辑。
5. 验收：默认进站首页首屏不再出现留言列表；展开后功能与现状完全一致（发帖/点赞/私聊/风控）。

### 3.5 顶部导航条（解决 P2 / 全局导航）

- `#status` 保留 34px 高度，内部改为三段：
  - 左：`WTZ·ROOT`（现有 `.st-l`，保留 ▮ 光标动画）
  - 中（仅桌面 ≥900px 显示）：链接组 档案室 / 论坛 / 学院 / 日志 / 地图（各指向对应文件，`color:var(--ink2)`，hover 变白）
  - 右：权限等级徽章（现有 `.pbadge` 保留）+ 搜索框（现有搜索逻辑入口保留）
- hero 精简：删除 L960 `FILE WTZ·ROOT · 4 入口` 行；`.h-sub` 改为一句定位语（如"黑白终端 · 数字宇宙入口"）；`h-mono` 保留。
- 移动端：隐藏中间链接组（CSS `@media(max-width:900px){…display:none}`），入口仍靠首页卡片。

### 3.6 CSS 变量落地（解决 P6，本页范围）

`:root` 新增（值取自 3.1，与本页现有 `--r/--bw/--sh` 并列）：

```css
:root{--sp-1:4px;--sp-2:8px;--sp-3:12px;--sp-4:16px;--sp-6:24px;--sp-8:32px}
```

- 本页所有硬编码间距替换为变量（如 `.block`、`.b-head`、`.card-bd`）。
- 圆角保持终端风直角（`--r:0px` 不变，不引入圆角）。

## 6. 风险与注意事项

1. **JS 复用红线**：`.gb` 内部 DOM 与事件绑定依赖现有结构，包裹时只在外层加容器，**不得**改动 `.gb` 内部任何 id / class / 结构。
2. **localStorage 键**：新增仅 `gb_collapsed` 一个键，不与现有键（`wzLv` / `gb_api_url` 等）冲突。
3. **云端同步**：纯前端改动，`_cloud\guestbook_server.py` 与云端合并逻辑不受影响，无需改服务端。
4. **备份**：Step 1 开工前 `index.html` → `_backup\index-UI重构前.html`。
5. **回滚**：任一步验收不通过，用备份文件回滚该步，修复后重试；不跨步混改。
6. 完成后更新 `changelog.html`（发布一条"UI 重构 v1"记录），并同步交接文档中 index 相关描述。
